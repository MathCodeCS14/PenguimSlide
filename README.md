# Penguin Slide 3.0

Abra no VS Code, rode `npm.cmd install` e depois `npm.cmd start`. Acesse http://localhost:3000.

Nesta versão o controle foi suavizado e acelerado um pouco, os obstáculos aparecem com menor frequência e o pinguim foi redesenhado em Canvas para ficar mais legível.

Versão final: velocidade aumentada e pinguim redesenhado em visão superior, de barriga para baixo, com corpo oval azul-escuro, patas atrás, bico triangular laranja e dois olhos no topo.

True Final: pinguim sem barriga branca, patas desenhadas primeiro para ficarem atrás do corpo, velocidade maior e obstáculos mais lentos para melhorar a jogabilidade.

Ultimate balance: pinguim muito mais rápido, obstáculos bem mais lentos e espaçados para uma jogabilidade mais confortável.
